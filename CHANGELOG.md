# Changelog

## v1.2.0

- EXE now targets public release assets with version `1.2.0`.
- Added administrator-required app manifest for the WPF EXE.
- Simplified the top shell: removed fake browser back/forward/home/search controls and mode toggle.
- Moved About to the Nokara brand button and removed About from the top tab strip.
- Kept a single advanced mode with confirmation for sensitive actions.
- Added visible pending-action notice and clearer disabled labels.
- Added PowerShell Tool GUI (`scripts/nokara-tool.ps1`).
- Updated PowerShell Lite to a 15-option safety-focused menu.
- Updated launcher to download the portable ZIP asset and validate SHA256 when available.
- Prepared release notes, docs and ignore rules for public GitHub Releases.

## v1.1.1

- Browser shell with top tabs and more horizontal room for content.
- Stronger desktop scrollbars for app content, tabs and DataGrid tables.
- Tab strip horizontal scroll with visible thumb and left/right buttons.
- GitHub public repository polish: README, docs, issue templates, gitignore and release notes.

## v1.1.0

- New Diagnostic section.
- Stuttering, RAM, per-game/global FPS, storage, network and streaming diagnostics.
- Final report on Desktop and `%AppData%\NokaraSystemManager\Reports`.
- PowerShell Lite safe TUI menu.
- PowerShell launcher for GitHub Releases.
- Social links in `Config/social-links.json`.
- GitHub-ready structure with docs, security, changelog, license and issue templates.
- Manual game paths in `%AppData%\NokaraSystemManager\Config\manual-paths.json`.

## v1.0.4

- Final visual polish.
- Native dark titlebar using DWM.
- Microcopy and text cleanup.
- More restrained premium UI for cards, chips, buttons and process tables.
